02 / GET STARTED

进门前，三件小事。

适用于 Mac M 系列版本。

  1. 一

    下载并解压

    在 GitHub 发布页选择带有 macOS-AppleSilicon 名称的 ZIP 文件，解压后找到「第三口人.app」。

  2. 二

    放进应用程序

    将「第三口人.app」拖到「应用程序」文件夹，再双击打开。游玩无需浏览器，也无需保持联网。

  3. 三

    允许首次打开

    测试版尚未经过 Apple 公证。如系统拦截，确认文件来自本页的 GitHub 仓库，再前往「系统设置 → 隐私与安全性」选择「仍要打开」。
